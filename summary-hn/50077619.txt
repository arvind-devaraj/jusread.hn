Show HN: Parsimony – an open-source benchmark for how much code AI models add  (70 pts, 14 comments)
https://news.ycombinator.com/item?id=50077619

The Hacker News discussion centers around "Parsimony," an open-source benchmark designed to evaluate the amount of code generated by AI models, focusing on the complexity and verbosity of the output rather than just the solve rate or token cost. The benchmark counts "coding units" from existing benchmarks and aims to provide a more meaningful measure of code quality for long-term projects. The creator invites feedback and contributions, especially public patch exports for newer models.

In the comments, users express a mix of agreement and concern regarding the implications of measuring code verbosity. Some argue that while excessive verbosity is undesirable, overly terse code can also be problematic, with examples like Astra producing unreadable code. Others discuss the need for better tools to reduce complexity and improve code quality, while some express skepticism about the relevance of such benchmarks, suggesting that AI will naturally improve over time.

Notable insights include the idea that effective AI coding requires proper guidance and tools to produce code that adheres to desired standards. There is also a recognition that measuring code quality at a syntactic level can help manage the complexities introduced by AI-generated code, highlighting the ongoing debate about balancing verbosity and clarity in AI outputs.
